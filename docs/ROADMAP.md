# Framework direction

Bead provides reusable Wayland shell infrastructure while leaving application identity and policy with each host. The framework's boundaries are recorded in [architecture decisions](decisions/) and the [B0214 split decision](specs/0214-framework-split.md).

Current priorities are independent framework builds, clear host configuration seams, stable UI and storage contracts, and useful minimal examples. Product roadmaps and feature specifications live with their owning application.
