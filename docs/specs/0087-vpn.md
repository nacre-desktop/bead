# B0087 — VPN tile and page

Status: **Review**. Consumes Nacre N0062 (`vpn` topic, `vpn.connect` / `vpn.disconnect`), pin ``e994f3ce``. The QML shell's
VPN tile and page (`NacreControlVpn`, `NacreVpn`, `nmcli`) are ported; nothing in QML or Nacre outside N0062 changed.
The QML VPN row in the retirement inventory goes from MISSING to Review.

## Design

- **Data, not code.** The tile is one entry in `shell/control/tiles.luau` (`source="vpn.state"`, `dock="vpn"`,
  `navigate=true`, `hide_unsupported=true`); the page is `shell/control/vpn-body.luau` on kit components (hint,
  `ToggleTile` rows, status line), listed in `shell/control/bundle.json`. Sizes, spacing and type come from the size-scale
  tokens; row height is the registry's `half` tile height. Rearranging or replacing the page needs no Rust change.
- **Adapter only at the edge.** `control_center.rs` (the one place that names Nacre topics) reads the `vpn` topic into the
  `vpn.state` source, projects the page rows (`cc.vpn`) and one status line (`cc.vpn_message`), and sends
  `switch:vpn.state:<id>` as `vpn.connect` or `vpn.disconnect` by the profile's published ID. Nothing else knows a Nacre id.
- **Tile.** On while any profile is active; status is the first active profile's name, else "Off" (QML). It stays visible
  with no saved profiles (QML) and **hides while the topic is absent, stale or unavailable** (B0076 rule), so Bead on an older
  daemon simply has no VPN tile. A press always opens the page and the chevron is the same opener (QML `navigation` tile).
- **Page rows.** One tile per saved profile, filled while active: "Connected", "Off", plus "Connecting…" and
  "Disconnecting…" (QML shows "Connected" while a profile is still activating). A press connects, or disconnects when
  active. Rows are inert while a change is in flight (QML `available: !busy`) or while the daemon does not offer the method.
- **Status line** (QML precedence): the failure text until the next attempt, else "Updating VPN connections…" while busy,
  else "No saved VPN profiles found."; "NetworkManager VPN controls are unavailable." when the topic is. The failure text
  shows after a refused call and also when N0062 reports the profile `failed` (the later activation error that QML saw through
  `nmcli --wait 30`).
- **Leases exist only while the control view is open**: `vpn` joins the panel's topic list (`TOPICS`); the existing lease
  retirement tests count it.
- **Secrets.** None cross Bead: no field, prompt or store; NetworkManager and the user's secret agents keep them (N0062).
- New general primitive: `navigate` on a tile registry entry (a toggle tile whose press opens its dock page and shows the
  chevron); it is data in `tiles.luau`, not a VPN special case, so it needs no ADR 0004 change.
- Temporary duplicates: none.

## Differences recorded

- Row order: QML lists profiles in nmcli's order, Bead (N0062) sorts by name; the same profile sits in a different row, so the
  hover/pressed arms target the idle "Work VPN" row in each. Real nmcli ordering is not reproduced by the stub, so it is untested.
- "Connecting…" / "Disconnecting…" are new wording; QML shows "Connected" while a profile activates.
- The engine's buttons activate on press, so the Bead pressed capture already shows "Connecting…"; QML activates on release
  (kit-wide behaviour, as for the other control tiles).
- Header (back button outline, 2-3 px lower title) and body glyph weight are the shared dock gaps recorded in B0076. The QML
  empty description line above the page is reproduced by a spacer token sum (30 px).
- Hint wrapping is estimated by character advance (`advance=.5`); it matches QML at this width, other fonts may wrap differently.
- `nacre controls vpn` is not a route (QML refuses it too); the page opens from the tile.
- A failure that arrives later (no secrets, login failed, timeout) is shown from the N0062 `failed` state; no in-app secret
  prompt exists in either shell. A real `nmcli` against the fake and a real VPN plugin were not exercised (fakes only).
- Not compared: animation timing of the page open (the shared dock transition is unchanged).
