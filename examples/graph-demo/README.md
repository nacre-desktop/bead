# Graph demo

A `kit.GraphCanvas` showing a synthetic seeded graph of 2,000 nodes and 10,000 edges (`view/graph.luau`, handed to Rust once with `ui.graph`). Force-directed layout runs on a worker thread and parks when settled; hovering shows the node label, a click selects, a double-click (or Enter on the keyboard-focused node) activates, arrows walk the focus between neighbours, Escape clears, dragging pans and the wheel zooms. Activating a node highlights it with the forty hubs and dims the rest (`highlight = ui.bind("highlight")`). The status line reports each event. Run `bead check examples/graph-demo` to validate and CPU-render it, or `bead run examples/graph-demo` inside a Wayland session.
